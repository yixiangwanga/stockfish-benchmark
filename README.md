Questo repository contiene gli script Python sviluppati per la tesi di laurea triennale dal titolo **"Analisi architetturale e valutazione delle prestazioni di Stockfish"**.

**Autore:** Yi Xiang Wang  
**Corso di Laurea:** Ingegneria informatica
**Anno Accademico:** 2025/2026 

Il codice è suddiviso in tre script principali:

* **`threadsTest.py`**: esegue comando bench variando il numero dei thread.
* **`fixedDepthTest.py`**: esegue una ricerca a profondità fissa.
* **`hashTest.py`**: esegue una ricerca variando la dimensione della tabella di trasposizione.
* **`hceNNUE.py`**: confronta le metriche di HCE e NNUE.
* **`tournament.py`**: simula un torneo di 100 partite.
